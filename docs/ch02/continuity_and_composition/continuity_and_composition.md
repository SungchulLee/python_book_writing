# 극한과 합성함수의 미분

함수의 연속성과 합성함수의 미분법은 미분의 두 기본 축이다. 이 절에서는 다항함수 $f(x)$ 와 그 "역함수 비슷한" 함수 $g(t)$ — 즉 $f(g(t)) = t$ 를 만족시키는 함수 — 의 연속성을 분석하고, 한쪽 극한과 합성함수의 미분법을 활용한다.

!!! note "사용 도구"
    1. **점에서의 연속성**: 함수 $f(x)$ 가 $x = a$ 에서 연속이려면 다음 세 조건이 모두 성립해야 한다.

        (i) $f(x)$ 가 $x = a$ 에서 정의되어 있다.

        (ii) 극한값 $\displaystyle\lim_{x \to a} f(x)$ 가 존재한다.

        (iii) $\displaystyle\lim_{x \to a} f(x) = f(a)$.

    2. **합성함수의 미분법**: 미분가능한 두 함수 $y = f(u)$, $u = g(x)$ 에 대하여

        $$
        \{f(g(x))\}' = f'(g(x))\,g'(x)
        $$

    3. **다항함수와 직선의 교점**: 다항함수 $f(x)$ 에 대하여 $g(t)$ 가 $f(g(t)) = t$ 를 만족시키면, $g(t)$ 는 곡선 $y = f(x)$ 와 직선 $y = t$ 의 교점의 $x$ 좌표 중 하나이다. 극한값 $\displaystyle\lim_{t \to t_0^{\pm}} g(t)$ 가 존재하면 그 값도 $y = f(x)$ 와 직선 $y = t_0$ 의 교점의 $x$ 좌표이다.

**연습문제 1.** [좌우극한 결정] 최고차항의 계수가 $1$ 인 삼차함수 $f(x)$ 와 실수 전체의 집합에서 정의된 함수 $g(t)$ 가 모든 실수 $t$ 에 대하여 $f(g(t)) = t$ 이고 다음을 만족시킨다.

!!! quote "조건"
    (1) $f(3) = 0$, $g(0) = -2$, $g(6) = 1$.

    (2) 함수 $g(t)$ 는 $t = 6$ 에서**만** 불연속이다.

$\displaystyle\lim_{t \to 6^-} g(t)$ 와 $\displaystyle\lim_{t \to 6^+} g(t)$ 의 값을 구하시오.

??? success "연습문제 1 풀이"

    **1단계 — $f$ 의 결정.** $g(0) = -2$ 이고 $f(g(0)) = 0$ 이므로 $f(-2) = 0$. 조건 (1)에 의해 $f(3) = 0$. 따라서 $f$ 는 $x = -2$ 와 $x = 3$ 을 근으로 가지므로

    $$
    f(x) = (x + 2)(x - 3)(x - a)
    $$

    인 실수 $a$ 가 존재한다. $g(6) = 1$ 이고 $f(g(6)) = 6$ 이므로 $f(1) = 6$:

    $$
    f(1) = (1 + 2)(1 - 3)(1 - a) = 3 \cdot (-2) \cdot (1 - a) = -6(1 - a) = 6
    $$

    이로부터 $1 - a = -1$, 즉 $a = 2$. 따라서

    $$
    f(x) = (x + 2)(x - 2)(x - 3) = x^3 - 3x^2 - 4x + 12
    $$

    <figure markdown>
      ![f(x) = (x+2)(x-2)(x-3) 의 그래프와 f(x) = 6 의 세 해 표시](figures/exercise1_setup.png){ width=620 }
      <figcaption markdown>$f(x) = (x+2)(x-2)(x-3)$ 의 그래프. 영점은 $-2, 2, 3$. 수평선 $y = 6$ 과 만나는 점의 $x$ 좌표는 $1 - \sqrt{7}, 1, 1 + \sqrt{7}$ 의 세 개 ($g(6)$ 은 그 중 가운데 값 $1$).</figcaption>
    </figure>

    **2단계 — $f(x) = 6$ 의 해.** $x^3 - 3x^2 - 4x + 12 = 6$ 즉 $x^3 - 3x^2 - 4x + 6 = 0$. $x = 1$ 이 근이므로 ($f(1) = 6$ 에서 확인됨) 인수분해하면

    $$
    x^3 - 3x^2 - 4x + 6 = (x - 1)(x^2 - 2x - 6) = 0
    $$

    이차식의 해는 $x = 1 \pm \sqrt{7}$. 따라서 $f(x) = 6$ 의 세 해는 $1 - \sqrt{7}$, $1$, $1 + \sqrt{7}$.

    **3단계 — 좌우극한.** $g$ 는 $t = 6$ 에서만 불연속이며, 좌우극한 $\displaystyle\lim_{t \to 6^\pm} g(t)$ 는 모두 존재 (조건상 단지 $g(6)$ 의 값과 다를 뿐). 제시문에 의하여 이 극한값들도 $f(x) = 6$ 의 해 중 하나이다.

    한편 $g$ 가 $t < 6$ 에서 연속이고 $g(0) = -2$ 이므로, $t$ 가 $0$ 에서 $6$ 으로 갈 때 $g(t)$ 는 $-2$ 에서 시작하여 좌측 단조 가지 ($f$ 가 증가하는 좌측 가지) 를 따라 움직인다. 이 가지는 좌측 임계점까지 이어지며, 가지 끝의 $x$ 좌표가 좌극한 후보. 따라서 좌극한은 $f(x) = 6$ 의 세 해 중 **가장 작은** $x$ 좌표여야 한다 (좌측 가지가 도달할 수 있는 가장 큰 $t$ 값이 좌측 극댓값이고, 그 직전까지 $x$ 가 증가). 결국

    $$
    \lim_{t \to 6^-} g(t) = 1 - \sqrt{7}
    $$

    마찬가지로 $t > 6$ 에서 $g$ 가 연속이며, $t \to \infty$ 일 때 $g(t) \to \infty$ 가 자연스러우려면 $g$ 는 우측 단조 가지 위에 있어야 한다. 따라서 우극한은 $f(x) = 6$ 의 세 해 중 **가장 큰** $x$ 좌표:

    $$
    \lim_{t \to 6^+} g(t) = 1 + \sqrt{7}
    $$

    (가운데 값 $1$ 은 $g(6)$ 자체이다.)

    <figure markdown>
      ![g(t) 의 궤적: t < 6 에서 좌측 가지, t = 6 에서 점프, t > 6 에서 우측 가지](figures/exercise1_g.png){ width=720 }
      <figcaption markdown>왼쪽: $g$ 가 $y = f(x)$ 위의 어느 가지를 따라가는지의 시각화. 빨강 가지 ($t < 6$) → 검정 점 $(1, 6)$ ($t = 6$ 의 값) → 보라 가지 ($t > 6$). 오른쪽: $g(t)$ 의 그래프. $t = 6$ 에서 점프 불연속, 좌우극한은 빈 원으로 표시 ($1 \mp \sqrt{7}$).</figcaption>
    </figure>

    $\square$

**연습문제 2.** [합성함수의 미분과 $h'(n)$ 계산] 최고차항의 계수가 $1$ 인 삼차함수 $f(x)$ 가 $x = 0$, $x = 2$ 에서 극값을 가질 때, 함수 $f(x)$ 와 실수 전체 집합에서 연속인 함수 $h(t)$ 는 다음 조건을 만족시킨다. (단, $n$ 은 자연수.)

!!! quote "조건"
    (1) 모든 $t \geq 0$ 에 대하여 $f(h(t)) = t + n$.

    (2) 실수 전체 집합에서 정의되고 다음을 만족시키는 함수 $k(t)$ 는 연속이 **아니다**:
    
    "모든 $t \geq 0$ 에 대하여 $f(k(t)) = t + n - 1$."

    (3) $f(1) = f(h(n))$.

$h'(n)$ 의 값을 구하시오.

??? success "연습문제 2 풀이"

    **1단계 — $f$ 의 형태와 극값.** $f'(x) = 0$ 의 해가 $x = 0, 2$ 이므로 $f'(x) = 3x(x - 2)$. 그러므로 $f(x) = x^3 - 3x^2 + c$ 의 형태. $x = 0$ 에서 극대값 $f(0) = c$, $x = 2$ 에서 극솟값 $f(2) = 8 - 12 + c = c - 4$. 극솟값을 $m_{\min}$ 이라 두면 $m_{\min} = c - 4$.

    **2단계 — $h$ 가 어느 가지에 있어야 하는가.** $h$ 가 모든 $t \geq 0$ 에서 연속이고 $f(h(t)) = t + n$ 이려면, $h$ 는 어떤 단조 가지 위를 연속적으로 움직여야 한다. $t + n$ 은 $[n, \infty)$ 를 치역으로 가지므로, $h$ 가 움직이는 가지의 치역 (즉 그 가지 위 $f$ 의 치역) 이 $[n, \infty)$ 를 포함해야 한다.

    - 좌측 가지 ($x \leq 0$): $f$ 가 $(-\infty, c]$ 로 치역 → 위쪽이 막혀 있어 $[n, \infty)$ 를 모두 포함 못함. 불가.
    - 중간 가지 ($0 \leq x \leq 2$): $f$ 가 $[c-4, c]$ 로 치역 → 유한 구간. 불가.
    - **우측 가지 ($x \geq 2$)**: $f$ 가 $[c-4, \infty)$ 로 치역. $[n, \infty)$ 를 포함하려면 $c - 4 \leq n$, 즉 $m_{\min} \leq n$.

    따라서 $h(t)$ 는 **우측 가지** 위에 있고 $m_{\min} \leq n$.

    **3단계 — $k$ 가 연속이 아닐 조건.** 같은 논리로 $f(k(t)) = t + n - 1$ ($t \geq 0$) 인 연속 $k$ 가 우측 가지 위에 존재하려면 $m_{\min} \leq n - 1$ 이어야 한다. 조건 (2) 가 이를 부정 하므로

    $$
    m_{\min} > n - 1
    $$

    종합하면

    $$
    n - 1 < m_{\min} \leq n
    \quad\Longleftrightarrow\quad
    n - 1 < c - 4 \leq n
    \quad\Longleftrightarrow\quad
    n + 3 < c \leq n + 4
    $$

    <figure markdown>
      ![n - 1 < m ≤ n 의 허용 영역](figures/exercise2_constraint.png){ width=620 }
      <figcaption markdown>$m = c - 4$ 의 그래프와 허용 영역 $n - 1 < m \leq n$ (녹색). $n = 2$ 일 때 $c = 6, m = 2$ (검정 점) 가 조건을 만족한다.</figcaption>
    </figure>

    **4단계 — 조건 (3) 으로부터 $c$ 결정.** $f(h(n)) = n + n = 2n$. 조건 (3) 의 $f(1) = f(h(n)) = 2n$ 에서

    $$
    f(1) = 1 - 3 + c = c - 2 = 2n \quad\Longrightarrow\quad c = 2n + 2
    $$

    이를 $n + 3 < c \leq n + 4$ 에 대입하면

    $$
    n + 3 < 2n + 2 \leq n + 4
    \quad\Longrightarrow\quad
    1 < n \leq 2
    \quad\Longrightarrow\quad
    n = 2
    $$

    따라서 $c = 6$, $f(x) = x^3 - 3x^2 + 6$.

    **5단계 — $h(2)$ 와 $h'(2)$.** $f(h(2)) = 2 + 2 = 4$, 즉 $x^3 - 3x^2 + 6 = 4$, $x^3 - 3x^2 + 2 = 0$. $x = 1$ 이 해이므로 인수분해

    $$
    x^3 - 3x^2 + 2 = (x - 1)(x^2 - 2x - 2) = 0
    $$

    이차식의 해는 $x = 1 \pm \sqrt{3}$. $h(2)$ 는 **우측 가지 ($\geq 2$)** 위의 해이므로 $h(2) = 1 + \sqrt{3}$.

    **6단계 — 합성함수의 미분으로 $h'(2)$.** $f(h(t)) = t + n$ 의 양변을 $t$ 에 대해 미분하면

    $$
    f'(h(t))\,h'(t) = 1
    \quad\Longrightarrow\quad
    h'(t) = \frac{1}{f'(h(t))}
    $$

    $f'(x) = 3x^2 - 6x = 3x(x - 2)$, $h(2) = 1 + \sqrt{3}$ 이므로

    $$
    f'(1 + \sqrt{3}) = 3(1 + \sqrt{3})\bigl((1 + \sqrt{3}) - 2\bigr) = 3(1 + \sqrt{3})(\sqrt{3} - 1) = 3(3 - 1) = 6
    $$

    따라서 $h'(2) = \dfrac{1}{6}\quad\square$

    <figure markdown>
      ![f(x) = x³ - 3x² + 6 의 그래프, h(2) = 1 + √3, 그리고 접선 (기울기 6)](figures/exercise2_solution.png){ width=620 }
      <figcaption markdown>$f(x) = x^3 - 3x^2 + 6$ ($n = 2$, $c = 6$). 극대점 $(0, 6)$ 과 극소점 $(2, 2)$ 가 표시되어 있다. $h(2) = 1 + \sqrt{3} \approx 2.732$ (빨간 점) 에서 $f$ 의 접선의 기울기는 $f'(1 + \sqrt{3}) = 6$. 합성함수 미분법으로부터 $h'(2) = 1/6$.</figcaption>
    </figure>

    !!! tip "큰 그림"
        이 문제는 **여러 단계의 조건이 시그마처럼 합쳐져 단 하나의 자연수 $n$ 만 가능하게 만드는** 정수해 결정 문제이다.

        1. **연속성 조건이 정의역을 제한**: $h$ 가 어느 가지에 있어야 하는지 (우측 가지) 가 정해진다.
        2. **불연속 조건이 부등식을 만듦**: $k$ 가 불연속이라는 조건이 $m_{\min} > n - 1$ 을 강요.
        3. **함숫값 조건이 등식을 줌**: $f(1) = f(h(n)) = 2n$ 에서 $c$ 와 $n$ 의 관계 결정.
        4. **세 조건의 교집합**: $n = 2$ 만 가능.

        마지막에 합성함수 미분법으로 $h'(t) = 1/f'(h(t))$ 라는 깔끔한 식이 도출되어, 단 한 번의 대입으로 $h'(n) = 1/6$ 이 결정된다.

**연습문제 (보충).** [합성함수 $g \circ f \circ g^{-1}$ 의 극값과 치역] 실수 전체의 집합에서 정의된 두 함수

$$
f(x) = x(x - 1)^2\,e^{2x},\qquad g(x) = -\frac{x}{\sqrt{1 + x^2}}
$$

가 있다. 다음에 답하시오.

(1) $g'(x)$ 를 구하고, $g$ 의 치역을 구하시오.

(2) $g$ 의 역함수 $g^{-1}(x)$ 를 구하고, $h(x) = (g \circ f \circ g^{-1})(x)$ 일 때 방정식 $h(x) = 0$ 의 해를 모두 구하시오.

(3) (2) 에서 정의된 $h(x)$ 의 극댓값과 극솟값을 각각 구하시오 (단, $\displaystyle\lim_{x \to -\infty} f(x) = 0$).

??? success "연습문제 (보충) 풀이"

    **(1) $g'(x)$ 와 $g$ 의 치역.**

    $g(x) = -x (1 + x^2)^{-1/2}$. 곱·합성 미분:

    $$
    g'(x) = -(1 + x^2)^{-1/2} - x \cdot \left(-\tfrac{1}{2}\right)(1 + x^2)^{-3/2}\cdot 2x = -\frac{1}{(1 + x^2)^{3/2}}
    $$

    $g'(x) < 0$ 이므로 $g$ 는 단조감소. $x \to \infty$ 에서 $g \to -1^+$, $x \to -\infty$ 에서 $g \to 1^-$. 따라서

    $$
    g \text{ 의 치역} = (-1,\,1)
    $$

    **(2) $g^{-1}$ 와 $h(x) = 0$ 의 해.**

    $y = -\dfrac{x}{\sqrt{1+x^2}}$ 를 $x$ 에 대해 풀자. $y^2 (1 + x^2) = x^2 \Rightarrow x^2 (1 - y^2) = y^2 \Rightarrow x = \pm \dfrac{y}{\sqrt{1 - y^2}}$. $g$ 가 감소이므로 $y$ 와 $x$ 의 부호가 반대, 즉

    $$
    g^{-1}(x) = -\frac{x}{\sqrt{1 - x^2}}\quad (-1 < x < 1)
    $$

    $h(x) = g(f(g^{-1}(x))) = 0 \Leftrightarrow f(g^{-1}(x)) = g^{-1}(0) = 0$ ($g$ 단조이고 $g(0) = 0$).

    $f(t) = t(t-1)^2 e^{2t} = 0 \Leftrightarrow t = 0$ 또는 $t = 1$.

    $g^{-1}(x) = 0 \Leftrightarrow x = 0$. $g^{-1}(x) = 1 \Leftrightarrow -\dfrac{x}{\sqrt{1-x^2}} = 1 \Leftrightarrow x = -\dfrac{\sqrt 2}{2}$.

    따라서 $h(x) = 0$ 의 해는 $x = 0,\;-\dfrac{\sqrt 2}{2}$.

    **(3) 극값과 치역.**

    합성함수 미분법: $h'(x) = g'(f(g^{-1}(x)))\cdot f'(g^{-1}(x))\cdot (g^{-1})'(x)$.

    $g'$ 과 $(g^{-1})'$ 은 항상 부호가 일정하다 ($g' < 0$, $(g^{-1})' = -1/(1-x^2)^{3/2} < 0$ — 합성도 음수). 따라서 $h'(x) = 0$ 의 부호는 $f'(g^{-1}(x))$ 의 부호와 같다.

    $f(x) = x(x-1)^2 e^{2x}$ 의 도함수를 전개하면 $f'(x) = (x + 1)(2x - 1)(x - 1) e^{2x}$. 따라서 $f'(t) = 0$ 의 해 $t = -1, \dfrac{1}{2}, 1$.

    $g^{-1}(x) = -1 \Leftrightarrow x = \dfrac{\sqrt 2}{2}$. $g^{-1}(x) = \dfrac{1}{2} \Leftrightarrow x = -\dfrac{1}{\sqrt 5} = -\dfrac{\sqrt 5}{5}$. $g^{-1}(x) = 1 \Leftrightarrow x = -\dfrac{\sqrt 2}{2}$.

    $f'(x) > 0$ 의 해는 $x > 1$ 또는 $-1 < x < \dfrac{1}{2}$. $g^{-1}$ 이 감소이므로 $h'(x) > 0$ 인 $x$ 의 범위는 $x < g(1) = -\dfrac{\sqrt 2}{2}$ 또는 $g(1/2) = -\dfrac{\sqrt 5}{5} < x < g(-1) = \dfrac{\sqrt 2}{2}$.

    증감표를 그리면 $h$ 는 $x = -\dfrac{\sqrt 2}{2}$ 에서 극댓값, $x = -\dfrac{\sqrt 5}{5}$ 에서 극솟값, $x = \dfrac{\sqrt 2}{2}$ 에서 다시 극댓값을 가진다.

    극값 계산:

    - $h\!\left(-\dfrac{\sqrt 2}{2}\right) = g(f(1)) = g(0) = 0$
    - $h\!\left(-\dfrac{\sqrt 5}{5}\right) = g\!\left(f\!\left(\dfrac{1}{2}\right)\right) = g\!\left(\dfrac{e}{8}\right) = -\dfrac{e/8}{\sqrt{1 + e^2/64}} = -\dfrac{e}{\sqrt{e^2 + 64}}$
    - $h\!\left(\dfrac{\sqrt 2}{2}\right) = g(f(-1)) = g(-4 e^{-2}) = \dfrac{4 e^{-2}}{\sqrt{1 + 16 e^{-4}}} = \dfrac{4}{\sqrt{e^4 + 16}}$

    또한 $\displaystyle\lim_{x \to 1^-} h(x) = \lim_{x \to -\infty} g(f(x)) = g(0) = 0$, $\displaystyle\lim_{x \to -1^+} h(x) = \lim_{x \to \infty} g(f(x))$ ($x \to \infty$ 에서 $f \to \infty$, $g \to -1$). 즉 $h$ 의 치역은 두 극댓값 중 큰 값과 $-1$ 사이.

    !!! info "교훈"
        - **합성함수의 극값**: $h = g \circ f \circ g^{-1}$ 의 극값은 단순히 $f$ 의 임계점 $t$ 에 대해 $h(g(t)) = g(f(t))$ 로 구한다. $g$ 가 단조이므로 $g$ 와 $g^{-1}$ 이 극의 위치를 보존한다.
        - 큰 그림: **켤레 (conjugation) $h = g \circ f \circ g^{-1}$ 는 $f$ 의 임계점·임계값을 $g$ 좌표계로 옮긴 것**과 같다.

**연습문제 (보충 2).** [삼차함수의 극값 분기와 미분불가능점]
삼차함수 $f(x)$ 에 대하여 실수 전체에서 연속인 함수

$$
g(x) = \begin{cases} -\dfrac{1}{2}\,x & (x \leq 0) \\ f(x) & (x > 0) \end{cases}
$$

가 다음 세 조건을 만족한다.

> (가) $\displaystyle\lim_{x \to \infty} \dfrac{|g(x)|}{x^3} = 1$
> (나) $g(x)$ 가 극값을 갖는 $x$ 의 값은 $\alpha$ 하나뿐이다 (단, $\alpha$ 는 실수).
> (다) $\displaystyle\int_{-1}^1 g(x)\,dx = 0$

(1) $f(x)$ 의 최고차항의 계수를 구하시오.

(2) 실수 $\alpha$ 의 값의 범위를 구하시오.

(3) 함수 $h(x) = |g(x) - f'(0)x|$ 에 대하여, $D = \{k : h(x) \text{ 가 } x = k \text{ 에서 미분가능하지 않다}\}$ 라 하자. $D$ 의 원소의 개수가 1이 되도록 하는 $\alpha$ 의 값을 모두 구하시오.

??? success "연습문제 (보충 2) 풀이"

    **(1).** (가) 에 의해 $|f(x)|$ 의 leading term 이 $x^3$ 이어야 하므로 최고차항 계수 $a = \pm 1$. $x = 0$ 에서 $g$ 의 연속: $g(0^-) = 0 = g(0^+) = f(0)$, 즉 $f(0) = 0$.

    $a = -1$ 일 경우 $g$ 의 그래프가 $x \to \infty$ 에서 $-\infty$ 로 발산하면서 양의 영역에서 극값을 2개 가질 수 있어 (나) 위반. $a = 1$ 일 때 단 하나의 극값을 갖는 경우가 존재.

    $\boxed{a = 1}$

    **(2).** $f(x) = x^3 + bx^2 + cx$ ($f(0) = 0$). $f'(x) = 3x^2 + 2bx + c$. (나)는 $g$ 가 단 한 점에서 극값을 갖는다는 뜻 — $f'(x) = 0$ 의 두 근 $\alpha > 0$, $\beta \leq 0$ 의 경우 양수 근 $\alpha$ 만 $x > 0$ 영역에 들어와 거기서만 극값.

    근과 계수의 관계: $\alpha + \beta = -2b/3$, $\alpha\beta = c/3$.

    (다) 조건을 이용해 $b, c$ 사이의 관계 유도. $\int_{-1}^0 (-x/2)dx + \int_0^1 (x^3 + bx^2 + cx) dx = 1/4 + (1/4 + b/3 + c/2) = 1/2 + b/3 + c/2 = 0 \Rightarrow 2b + 3c = -3$.

    또한 $\beta = (-2b - 3\alpha \cdot 3)/3$... 케이스 분석 후 $\alpha = \dfrac{1 - \beta}{1 - 3\beta}$ 같은 관계로부터 $\beta \leq 0$ 와 $\alpha > 0$ 동시 만족 영역에서

    $$
    \boxed{\dfrac{1}{3} < \alpha \leq 1}
    $$

    **(3).** $D$ 의 원소 개수가 1이 되는 임계 $\alpha$: 풀이 (별해 1, 2) 에 의하여

    $$
    \alpha = \dfrac{1}{4} + \dfrac{\sqrt{33}}{12} \quad\square
    $$

    !!! info "교훈"
        - **piecewise 함수의 극값 카운팅**: 분기마다 극값이 나타날 가능성과 분기점 ($x = 0$) 에서의 미분가능성을 별도로 확인한다.
        - 절댓값 함수 $|F(x)|$ 의 미분불가능점은 $F(x) = 0$ 인 점들. $D$ 의 원소 수가 곧 $g(x) - f'(0)x = 0$ 의 단순근 수.

**연습문제 (보충 3).** [3차방정식 두 근의 세제곱 + 접선과 그래프 교점] $f(x) = x^3 - 6x^2$, $g(x) = \dfrac{3}{2}x - \dfrac{11}{2}$ 라 하자.

(1) 방정식 $f(x) - g(x) = 0$ 의 유리수가 아닌 두 근을 $\alpha, \beta$ 라 할 때 $L = \alpha^3 + \beta^3$.

(2) 방정식 $f(x) - mx + m + 4 = 0$ 의 서로 다른 실근의 개수가 $2$ 개가 되는 상수 $m$ 의 값.

??? success "연습문제 (보충 3) 풀이"

    **(1).** $f(-1) - g(-1) = -1 - 6 - (-3/2 - 11/2) = -7 + 7 = 0$. 즉 $f - g$ 는 $(x + 1)$ 을 인수로 가진다. 조립제법으로

    $$
    f(x) - g(x) = (x + 1)\left(x^2 - 7x + \frac{11}{2}\right)
    $$

    유리수가 아닌 두 근 $\alpha, \beta$ 는 $x^2 - 7x + 11/2 = 0$ 의 두 근. 근과 계수 $\alpha + \beta = 7$, $\alpha\beta = 11/2$.

    $$
    L = \alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta) = 343 - 3 \cdot \frac{11}{2} \cdot 7 = 343 - \frac{231}{2} = \frac{455}{2}\quad\square
    $$

    **(2).** $h(x) = m(x - 1) - 4$ 로 두면 $f(x) - h(x) = 0$ 의 서로 다른 실근이 $2$ 개여야. 곡선 $y = f(x)$ 와 직선 $y = h(x)$ 가 두 점에서 만나면서 한 점에서 접선이 되어야.

    접점의 $x$ 좌표를 $p$ 라 두면 $(p, f(p))$ 에서의 접선

    $$
    y = 3(p^2 - 4p)(x - p) + p^3 - 6p^2 = h(x)
    $$

    $h(1) = -4$ 이므로 $-4 = 3(p^2 - 4p)(1 - p) + p^3 - 6p^2 = -2p^3 + 9p^2 - 12p$, 즉 $2p^3 - 9p^2 + 12p - 4 = 0$. 인수분해: $(p - 2)^2(p - 1/2) = 0$. $p = 2$ 또는 $p = 1/2$.

    - $p = 2$: $m = 3(4 - 8) = -12$, $f - h = (x - 2)^3$ 단 한 실근만 — 조건 위반.
    - $p = 1/2$: $m = 3(1/4 - 2) = -21/4$, $f - h = (x - 1/2)^2 (x - 5)$ — 서로 다른 두 실근 $x = 1/2, 5$. 조건 만족.

    $\boxed{m = -\dfrac{21}{4}}\quad\square$

**연습문제 (보충 4).** [piecewise 함수 + 합성 극한 + 치환적분]
다항함수 $f(x)$ 에 대하여 $g(x) = \begin{cases} 3x & (x < 0, x > 3) \\ f(x) & (0 \le x \le 3)\end{cases}$, $h(x) = \displaystyle\lim_{t \to 0+} g(x + t) \cdot \lim_{t \to 3+} g(x + t)$. $h(x)$ 가 모든 실수에서 연속이고 $\displaystyle\int_{-5}^5 h(x)\,dx = 600$ 일 때

(1) $f(0) + f(3)$. (2) $\displaystyle\int_0^3 x f(x)\,dx$.

??? success "연습문제 (보충 4) 풀이"

    $\displaystyle\lim_{t\to 0+} g(x+t) = \begin{cases} 3x & x < 0 \\ f(x) & 0 \le x \le 3 \\ 3x & x > 3\end{cases}$, $\displaystyle\lim_{t\to 3+} g(x+t) = \begin{cases} 3(x+3) & x < -3 \\ f(x+3) & -3 \le x \le 0 \\ 3(x+3) & x > 0\end{cases}$.

    $h(x)$ 의 명시적 형태:
    - $x < -3$: $h = 3x \cdot 3(x+3) = 9x(x+3)$
    - $-3 \le x < 0$: $h = 3x \cdot f(x+3)$
    - $0 \le x \le 3$: $h = f(x) \cdot 3(x+3)$
    - $x > 3$: $h = 3x \cdot 3(x+3)$

    $h$ 연속 조건: $x = -3$ 에서 $-9 \cdot 0 = 9(-3)\cdot 0 \;\checkmark$; $x = 0$ 에서 $0 \cdot f(3) = f(0) \cdot 9 = 9 f(0)$ → $f(0) = 0$; $x = 3$ 에서 $f(3) \cdot 18 = 9 \cdot 3 \cdot 6 = 162$ → $f(3) = 9$.

    $f(0) + f(3) = 0 + 9 = 9$.

    **적분.** $\int_{-5}^5 h dx = \int_{-5}^{-3} 9x(x+3)dx + \int_{-3}^0 3x f(x+3) dx + \int_0^3 3 f(x)(x+3) dx + \int_3^5 9x(x+3) dx$.

    첫째 = $78$, 넷째 = $510$. 그러므로 $\int_{-3}^0 3x f(x+3) dx + \int_0^3 3 f(x)(x+3) dx = 12$.

    치환 $t = x + 3$ (첫 적분): $\int_0^3 3(t-3) f(t) dt$. 두 합 = $\int_0^3 [3(x-3) f(x) + 3 f(x)(x+3)] dx = \int_0^3 6 x f(x) dx = 12$.

    $\boxed{\int_0^3 x f(x) dx = 2}\quad\square$

**연습문제 (보충 5).** [piecewise 함수의 미분가능성 + 기울기와 교점]
양수 $a$ 와 상수 $b$, $f(x) = \begin{cases} 2x/(x^2 + a) & (x \ge 0) \\ bx & (x < 0)\end{cases}$. 실수 $t$ 와 양수 $c$ 에 대하여 닫힌구간 $[t, t+c]$ 에서의 $f$ 의 최댓값을 $g(t)$ 라 하자.

조건: (가) $f(x) \le f(c)$ for all $x \ge 0$. (나) $g(t)$ 는 $t = -1/2$ 에서 미분가능하지 않다. (다) 직선 $y = mx + 1/c$ 가 (나) $m = 1/25$ 에서 $y = g(t)$ 와 두 점, (다) $0 < m < 1/25$ 에서 세 점에서 만난다.

$a, b, c$ 의 값을 구하시오.

??? success "연습문제 (보충 5) 풀이 (요약)"

    (가) 에서 $f'(c) = (2a - 2c^2)/(c^2+a)^2 = 0 \Rightarrow a = c^2$, $f(c) = 1/c$.

    (나) $b \ge 0$ 인 경우의 $g(t)$ 의 piecewise 형태를 분석하면 $c = 1/2$ 가 강제. 그러나 (다) 조건이 $b \ge 0$ 에서 만족 안 됨.

    $b < 0$ 인 경우: $f(-\alpha) = f(c - \alpha)$ 를 만족하는 $\alpha \in (0, c)$ 가 존재해야 하고 (나) 가 $\alpha = 1/2 < c$ 이도록.

    $g$ 의 그래프 분석 + 직선 $y = mx + 1/c$ 가 $(0, 1/c)$ 와 $(-1/2, -b/2)$ 를 지나는 기울기 = $1/25$ 조건에서

    $$
    b = \dfrac{1}{25} - \dfrac{2}{c}
    $$

    이를 $b = -4(c - 1/2)/((c-1/2)^2 + c^2)$ 와 연결하면 $8c^3 - 4c^2 + c - 50 = 0$, 즉 $(c - 2)(8c^2 + 12c + 25) = 0$. $c = 2$.

    $\boxed{a = 4,\;b = -24/25,\;c = 2}\quad\square$

**연습문제 (보충 6).** [합성함수 + 속도·가속도 + 삼차함수 결정]
모든 실수 $t$ 에서 $g(t) \ge 0$ 이고 이계도함수를 갖는 함수가 있다. 좌표평면 위를 움직이는 점 $\mathrm{P}$ 의 시각 $t\;(0 \le t \le 4)$ 에서의 위치를 $(t, g(t))$ 라 하자. 점 $\mathrm{P}$, 함수 $f(x)$ 와 함수 $h(t) = f(g(t))$ 가 다음 조건을 만족한다.

(1) $t = 1/4$ 일 때 점 $\mathrm{P}$ 는 $x$ 축 위에 있고 가속도는 $(0, 1)$ 이다.
(2) $t = 1$ 일 때 점 $\mathrm{P}$ 의 속력이 최대가 되고, 이때 속력은 $\sqrt 2$ 이다.
(3) $f(x)$ 는 최고차항의 계수가 $1$ 인 삼차함수이고, $x \ge 0$ 인 모든 $x$ 에 대하여 $f'(x) > 0$.
(4) $h(1/4) = 0$, $h'(1) = 9/4$, $h''(1/4) = 4$, $h''(1) = -2$.

$f(3)$ 의 값을 구하시오.

??? success "연습문제 (보충 6) 풀이 (요약)"

    조건 (2): $\sqrt{1 + \{g'(t)\}^2}$ 가 $t = 1$ 에서 최대 ⇒ $g'(1)g''(1) = 0$. 또 $\sqrt{1 + g'(1)^2} = \sqrt 2 \Rightarrow g'(1) = \pm 1$. 조건 (3) 과 양수 조건으로 $g'(1) = 1$, $g''(1) = 0$.

    $h(t) = f(g(t))$ 의 미분: $h'(t) = f'(g(t))g'(t)$, $h''(t) = f''(g(t))(g'(t))^2 + f'(g(t))g''(t)$.

    $t = 1$: $h'(1) = f'(g(1))\cdot 1 = 9/4$, $h''(1) = f''(g(1)) + 0 = -2$. 즉 $f'(g(1)) = 9/4$, $f''(g(1)) = -2$.

    $t = 1/4$: $h(1/4) = f(g(1/4)) = 0$. $g(1/4) = $ ? 조건 (1) 가속도 $(0, 1)$ — $\mathrm{P}$ 의 가속도는 $(0, g''(t))$, 따라서 $g''(1/4) = 1$. 점 $\mathrm{P}$ 가 $x$ 축에 있으므로 $g(1/4) = 0$. 따라서 $f(0) = 0$.

    또한 $g(t) \ge 0$ 이고 $g(1/4) = 0$ 이므로 $g'(1/4) = 0$ (극소). $h''(1/4) = f''(0) \cdot 0 + f'(0) \cdot g''(1/4) = f'(0) = 4$.

    $f(x) = x^3 + ax^2 + bx$ ($f(0) = 0$ 이고 최고차 계수 $1$). $f'(x) = 3x^2 + 2ax + b$, $f'(0) = b = 4$. 따라서 $f(x) = x^3 + ax^2 + 4x$.

    $g(1) = b'$ 로 두면 (모를 미지수), $f'(b') = 3b'^2 + 2ab' + 4 = 9/4$ 즉 $3b'^2 + 2ab' + 7/4 = 0$. $f''(b') = 6b' + 2a = -2$ 즉 $3b' + a = -1$.

    두 식 연립: $a = -1 - 3b'$, $3b'^2 + 2(-1-3b')b' + 7/4 = 0 \Rightarrow 3b'^2 - 2b' - 6b'^2 + 7/4 = 0 \Rightarrow -3b'^2 - 2b' + 7/4 = 0$. 양수 해 $b' = 1/2$ (또는 음수 $-7/6$, $g \ge 0$ 에 위반).

    $a = -1 - 3/2 = -5/2$. $f(x) = x^3 - \dfrac{5}{2}x^2 + 4x$. $f(3) = 27 - 45/2 + 12 = 39 - 45/2 = \dfrac{33}{2}$.

    $\boxed{f(3) = \dfrac{33}{2}}\quad\square$

**연습문제 (보충 7).** [다항함수 × piecewise 함수의 연속·미분가능·도함수 극한]

다항함수 $f(x)$ 가 $f(2) = 4$ 를 만족하고, 함수 $g(x)$ 는 다음과 같다.

$$
g(x) = \begin{cases} |x + 1| & (x \le 0) \\ \dfrac{1}{x} & (0 < x \le 1) \\ x & (x > 1) \end{cases}
$$

(1) $f(x)\,g(x)$ 가 실수 전체에서 연속이 되도록 하는 $f(x)$ 중 차수가 최소인 것을 구하시오.

(2) $f(x)\,g(x)$ 가 실수 전체에서 미분가능하도록 하는 $f(x)$ 중 차수가 최소인 것을 구하시오.

(3) (2) 에서 구한 $f$ 에 대하여 다음 세 극한값을 구하시오.

$$
\lim_{x \to 1^-} \bigl(f(x)\,g(x)\bigr)',\qquad \lim_{x \to 1^+} \bigl(f(x)\,g(x)\bigr)',\qquad \lim_{x \to \infty} \frac{\ln\bigl(1 + |f(x)|\bigr)}{\ln x}
$$

??? success "연습문제 (보충 7) 풀이"

    **불연속·미분불가능 위치 점검.** $g(x)$ 는 $x = -1$ 에서 절댓값의 꺾임 (연속이지만 미분불가능), $x = 0$ 에서 $|x+1| = 1$ 이지만 $1/x \to \pm \infty$ 즉 **우극한 발산** (불연속), $x = 1$ 에서 $1/x = 1 = x$ (연속이지만 도함수 불일치: 좌도함수 $-1$, 우도함수 $1$, 미분불가능).

    **(1).** $x = 0$ 에서 $f(x)g(x)$ 연속 ⇒ $f(0) \cdot \lim_{x \to 0^+} 1/x$ 가 유한 ⇒ $f(0) = 0$ 이고 $\lim_{x \to 0^+} f(x)/x$ 가 유한. $f(x) = x^n h(x)$ ($n \ge 1$, $h(0) \ne 0$) 로 두면 $\lim_{x \to 0^+} f(x) g(x) = \lim x^{n-1} h(x)$ 이 $0$ 이려면 $n \ge 2$. 또 $f(0) g(0) = 0$, 좌극한 $\lim_{x \to 0^-} f(x)|x+1| = f(0) = 0$ — 일치.

    가장 작은 차수: $n = 2$, $f(x) = x^2 h(x)$ 의 차수 최소 ⇒ $h(x) = $ 상수. $f(2) = 4 \cdot h = 4 \Rightarrow h = 1$. **답: $f(x) = x^2$**.

    **(2).** $x = -1, 0, 1$ 모두에서 미분가능해야 한다. (1) 의 분석에서 $f(0) = 0$. $x = 1$ 에서: 좌극한 $\lim_{x \to 1^-} (f \cdot 1/x)' = \lim (f'(x)/x - f(x)/x^2)|_{x=1^-} = f'(1) - f(1)$. 우극한 $(f \cdot x)'|_{x=1^+} = f'(1) + f(1)$. 두 값이 같으려면 $f(1) = 0$. 같은 방식 $x = -1$ 에서: $f(-1) = 0$.

    그러므로 $f(x) = x^a (x-1)^b (x+1)^c h(x)$ ($a, b, c \ge 1$, $h(\pm 1) h(0) \ne 0$). 미분가능 조건은 각 점에서 좌·우 도함수 일치. 정확한 차수 조건 (제시문의 [채점기준] 풀이) 으로 $a \ge 3$, $b \ge 1$, $c \ge 1$. 차수 최소 ⇒ $a = 3$, $b = 1$, $c = 1$, $h$ 상수. $f(2) = 2^3 \cdot 1 \cdot 3 \cdot h = 24h = 4 \Rightarrow h = 1/6$. **답: $f(x) = \dfrac{1}{6} x^3 (x - 1)(x + 1)$**.

    **(3).** (2) 의 $f$. $x \to 1^\pm$ 에서 $f(x) g(x)$:

    - $0 < x \le 1$: $f(x) g(x) = \dfrac{f(x)}{x} = \dfrac{1}{6} x^2 (x^2 - 1)$. 도함수 $\dfrac{1}{3} x(x^2 - 1) + \dfrac{1}{6} x^2 \cdot 2x = \dfrac{1}{3}x(x^2 - 1) + \dfrac{1}{3} x^3$. $x \to 1^-$ 대입: $\dfrac{1}{3} \cdot 1 \cdot 0 + \dfrac{1}{3} = \dfrac{1}{3}$.

    - $x > 1$: $f(x) g(x) = x \cdot f(x) = \dfrac{1}{6} x^4 (x^2 - 1)$. 도함수 $\dfrac{2}{3} x^3 (x^2 - 1) + \dfrac{1}{6} x^4 \cdot 2x = \dfrac{2}{3} x^3(x^2 - 1) + \dfrac{1}{3} x^5$. $x \to 1^+$: $0 + \dfrac{1}{3} = \dfrac{1}{3}$.

    두 극한 모두 $\boxed{1/3}$. (미분가능 조건의 자체 검증.)

    세 번째 극한: $|f(x)| = \dfrac{1}{6} |x|^3 |x^2 - 1|$. $x \to \infty$ 이므로 $|f(x)| \sim x^5/6$. $\ln(1 + |f(x)|) \sim \ln(x^5/6) = 5 \ln x - \ln 6$. 따라서

    $$
    \lim_{x \to \infty} \frac{\ln(1 + |f(x)|)}{\ln x} = \lim_{x \to \infty} \frac{5 \ln x + O(1)}{\ln x} = 5\quad\square
    $$

    !!! tip "큰 그림"
        - **불연속 지점 $x = 0$ 에서 발산 $1/x$**: $f$ 의 $x$ 인수가 발산을 흡수해야 연속. 차수 최소 → $x^2$.
        - **미분가능에서 $x = \pm 1$ 의 꺾임 / 도함수 불일치**: $f$ 가 $(x-1)$, $(x+1)$ 의 인수를 가져 곱이 매끄럽게 이어지도록 만든다. $x = 0$ 의 미분가능은 $x^3$ 인수까지 강화.
        - **무한대 극한 = 차수 비**: $\ln(1 + |f|)/\ln x$ 의 무한대 극한은 $f$ 의 차수 $= 5$ 와 일치.

**연습문제 (보충 8).** [사차함수의 정수 betweenness + 평균변화율]

최고차항의 계수가 $1$ 이고 삼차항의 계수가 $a$ 인 사차함수 $f(x)$ 가 다음을 만족한다.

> 모든 정수 $k$ 에 대하여 $f(k-2) \le f(k) \le f(k+2)$ 또는 $f(k-2) \ge f(k) \ge f(k+2)$ 이다.

함수 $g(x) = \dfrac{f(x+1) - f(x-1)}{2}$.

(1) $g(x) - f'(x)$ 를 간단히 하시오.

(2) $a = 1$ 일 때, 방정식 $g(x) = 0$ 의 근을 모두 구하시오.

(3) $f\!\left(\dfrac{1}{4}\right) = f\!\left(\dfrac{9}{4}\right)$ 일 때, 도함수 $f'(x)$ 를 모두 구하시오.

??? success "연습문제 (보충 8) 풀이"

    $f(x) = x^4 + a x^3 + b x^2 + c x + d$ 로 두자.

    **(1).** $(x+1)^k - (x-1)^k$ 를 직접 전개:

    - $k = 4$: $(x+1)^4 - (x-1)^4 = 8x^3 + 8x$.
    - $k = 3$: $6x^2 + 2$.
    - $k = 2$: $4x$.
    - $k = 1$: $2$.

    $f(x+1) - f(x-1) = (8x^3 + 8x) + a(6x^2 + 2) + b(4x) + 2c$. 양변을 $2$ 로 나누면

    $$
    g(x) = 4x^3 + 3a x^2 + (2b + 4)x + (a + c)
    $$

    한편 $f'(x) = 4x^3 + 3a x^2 + 2b x + c$. 빼면

    $$
    g(x) - f'(x) = 4x + a\quad\square
    $$

    (평균변화율과 순간변화율의 **선형 보정 항**.)

    **(2).** 조건은 $f(k+2) - f(k)$ 와 $f(k) - f(k-2)$ 가 같은 부호. 한편 $f(k+2) - f(k) = 2\,g(k+1)$, $f(k) - f(k-2) = 2\,g(k-1)$ 이므로 (←$g(j) = (f(j+1) - f(j-1))/2$ 정의) 조건은

    $$
    g(k+1)\,g(k-1) \ge 0\quad (\forall k \in \mathbb{Z})
    $$

    즉 같은 패리티의 인접 정수쌍에서 $g$ 의 부호가 같음 (또는 한쪽이 $0$). $g$ 는 최고차 양수 $4$ 인 삼차이므로 $-\infty \to +\infty$ 로 부호가 바뀐다. 부호 변화가 같은 패리티 정수쌍을 가로지르지 않게 하려면 **$g$ 가 두 개의 이웃한 정수 $n, n+1$ 에서 $0$ 이 되어야** 한다. 나머지 한 근을 $\alpha$ 라 하면

    $$
    g(x) = 4(x - n)(x - n - 1)(x - \alpha)
    $$

    부호 분석으로 $\alpha \in [n - 1, n + 2]$ 가 필요. 전개의 $x^2$ 계수를 비교: $4(-n-(n+1)-\alpha) = -4(2n+1+\alpha) \stackrel{!}{=} 3a$.

    $a = 1$ 대입: $2n + 1 + \alpha = -3/4$ ⇒ $\alpha = -2n - 7/4$. 부호 범위 $n-1 \le \alpha \le n+2$:

    - $n - 1 \le -2n - 7/4$ ⇒ $n \le -1/4$ ⇒ $n \le -1$.
    - $-2n - 7/4 \le n + 2$ ⇒ $n \ge -5/4$ ⇒ $n \ge -1$.

    따라서 $n = -1$, $\alpha = 1/4$. 근: $\boxed{-1,\ 0,\ 1/4}\quad\square$

    **(3).** $f(9/4) - f(1/4) = 2\,g(5/4) = 0$ 이므로 $5/4$ 는 $g$ 의 근. (2) 의 분석에서 $g$ 의 근은 두 이웃한 정수 $n, n+1$ 과 $\alpha \in [n-1, n+2]$ 이고 $5/4$ 가 정수가 아니므로 $\alpha = 5/4$. $5/4 \in [n-1, n+2]$:

    $$
    n - 1 \le 5/4 \le n + 2\quad\Longrightarrow\quad -3/4 \le n \le 9/4\quad\Longrightarrow\quad n \in \{0, 1, 2\}
    $$

    각 $n$ 에 대해 $g(x) = 4(x-n)(x-n-1)(x - 5/4)$ 를 전개한 뒤 $x^2$ 계수에서 $a = -\dfrac{4(2n + 1 + 5/4)}{3} = -\dfrac{8n + 9}{3}$ 를 얻고, $f'(x) = g(x) - 4x - a$ 로 환원한다.

    - **$n = 0$**: $g(x) = 4x(x-1)(x - 5/4) = 4x^3 - 9x^2 + 5x$, $a = -3$.

        $$
        f'(x) = 4x^3 - 9x^2 + 5x - 4x + 3 = 4x^3 - 9x^2 + x + 3
        $$

    - **$n = 1$**: $g(x) = 4(x-1)(x-2)(x - 5/4) = 4x^3 - 17x^2 + 23x - 10$, $a = -17/3$.

        $$
        f'(x) = 4x^3 - 17x^2 + 23x - 10 - 4x + 17/3 = 4x^3 - 17x^2 + 19x - \dfrac{13}{3}
        $$

    - **$n = 2$**: $g(x) = 4(x-2)(x-3)(x - 5/4) = 4x^3 - 25x^2 + 49x - 30$, $a = -25/3$.

        $$
        f'(x) = 4x^3 - 25x^2 + 49x - 30 - 4x + 25/3 = 4x^3 - 25x^2 + 45x - \dfrac{65}{3}\quad\square
        $$

    !!! tip "큰 그림"
        - **핵심 항등식 $g(x) - f'(x) = 4x + a$**: 평균변화율 (스텝 $1$ 의 대칭차분몫) 과 순간변화율의 차가 사차함수에서는 선형. 차분의 차수가 미분보다 ${\rm deg} - 1$ 작게 떨어지지 않고 등가의 도함수 + 보정으로 표현된다는 통찰.
        - **정수 betweenness ⇒ $g(k+1) g(k-1) \ge 0$**: 차분의 부호가 같은 패리티에서 일정. 삼차 $g$ 가 $-\infty \to +\infty$ 로 부호를 바꾸려면 두 이웃 정수 근 + 좁은 구간의 비정수 근의 구조가 강제된다.
        - **(3) 의 $5/4$**: $f(1/4) = f(9/4)$ 의 중점이 $5/4$ 이므로 $g(5/4) = 0$. $5/4$ 가 비정수이므로 $\alpha = 5/4$, $n$ 의 후보 $\{0, 1, 2\}$ 가 자연스럽게 나온다. 세 답이 공존하는 것은 조건이 $f$ 를 일의적으로 결정하지 않기 때문.

**연습문제 (보충 9).** [구간 최솟값 위치로 사차함수 결정 + 합성함수의 미분가능]

**(1)** 사차함수 $p(x)$ 의 최고차항의 계수가 $1$ 이다. 실수 $t$ 에 대하여 다음 조건을 만족하는 실수 $\alpha$ 의 최댓값을 $g(t)$ 라 하자.

> 구간 $(-\infty, t]$ 에서 $p(x)$ 는 $x = \alpha$ 일 때 최솟값을 갖는다. (단, $\alpha \le t$.)

함수 $g(t)$ 가

$$
g(t) = \begin{cases} t & (t < 0) \\ 0 & (0 \le t < 2) \\ t & (2 \le t < 3) \\ 3 & (t \ge 3) \end{cases}
$$

가 되도록 하는 $p(x)$ 에 대하여 $p(1) - p(0)$ 의 값을 구하시오.

**(2)** 사차함수 $q(x)$ 가 $q(0) = 2$, $q(1) = \dfrac{23}{8}$ 을 만족하고, $f(x) = -\cos\dfrac{\pi q(x)}{4}$ 이다. 함수 $h(t)$ 는 실수 전체에서 다음과 같이 정의된다.

> (i) $h(0) = 0$.
> (ii) $t > 0$ 이면, 구간 $[0, t]$ 에서 $f(x)$ 가 $x = \alpha$ 일 때 최댓값을 갖도록 하는 $\alpha$ 중 최솟값이 $h(t)$ 이다 ($0 \le \alpha \le t$).
> (iii) $t < 0$ 이면, 구간 $[t, 0]$ 에서 $f(x)$ 가 $x = \alpha$ 일 때 최댓값을 갖도록 하는 $\alpha$ 중 최댓값이 $h(t)$ 이다 ($t \le \alpha \le 0$).

합성함수 $(q \circ h)(t)$ 가 실수 전체에서 미분가능하도록 하는 사차함수 $q(x)$ 를 모두 구하시오.

??? success "연습문제 (보충 9) 풀이"

    **(1).** $g$ 의 모양으로부터 $p(x)$ 의 개형을 읽어낸다.

    - $t < 0$ 에서 $g(t) = t$: $(-\infty, t]$ 에서 최솟값 위치가 $t$, 즉 $p$ 가 $(-\infty, 0)$ 에서 감소.
    - $0 \le t < 2$ 에서 $g(t) = 0$: 최솟값 위치가 $0$ 으로 고정. 즉 $p$ 는 $x = 0$ 에서 극소.
    - $t = 2$ 에서 $g$ 가 $0$ 에서 $2$ 로 점프: $p(2) = p(0)$ 이고 직후 새로운 최솟값 위치 $t$ 가 후보가 됨.
    - $2 \le t < 3$ 에서 $g(t) = t$: $p$ 가 $[2, 3)$ 에서 감소.
    - $t \ge 3$ 에서 $g(t) = 3$: $p$ 가 $x = 3$ 에서 극소.

    그러므로 $p'(x) = 4 x (x - a)(x - 3)$ ($0 < a < 3$, $x = a$ 에서 극대). 적분:

    $$
    p(x) = x^4 - \tfrac{4(a + 3)}{3} x^3 + 6 a x^2 + C
    $$

    조건 $p(2) = p(0) = C$:

    $$
    16 - \frac{32(a + 3)}{3} + 24 a = 0\quad\Longleftrightarrow\quad -16 + \frac{40 a}{3} = 0\quad\Longleftrightarrow\quad a = \frac{6}{5}
    $$

    따라서 $p(x) = x^4 - \dfrac{28}{5} x^3 + \dfrac{36}{5} x^2 + C$.

    $$
    p(1) - p(0) = 1 - \frac{28}{5} + \frac{36}{5} = 1 + \frac{8}{5} = \frac{13}{5}\quad\square
    $$

    **(2).** $f(x) = -\cos(\pi q(x)/4)$. $f$ 의 최댓값 $1$ 은 $\cos(\pi q/4) = -1$, 즉 $q(x) \equiv \pm 2 \pmod 8$. 최댓값 후보들은 $q(x) \in \{\dots, -6, 2, -2, 6, \dots\}$.

    $h$ 의 미분가능: $x = 0$ 에서 $q'(0) = 0$ 이어야 한다 ($h'(0^-) = 0$, $h'(0^+) = 1$ 일 때 $(q \circ h)'(0^-) = q'(h(0))\cdot 0 = 0$, $(q \circ h)'(0^+) = q'(0) \cdot 1$; 일치 필요). $q'(0) = 0$.

    $q$ 의 최고차항의 계수가 양수라고 가정하면 $q$ 의 그래프 개형에서 모순 (예시 답안의 사잇값 정리 분석). 따라서 $q$ 의 최고차항의 계수는 음수. $q(0) = 2$ 이고 $q$ 가 $x = 0$ 에서 임계점, 그리고 두 양/음 임계점 $\beta, \alpha = -\beta$ 에서 $q(\pm \beta) = 4$ ($f$ 의 최댓값이 발생하는 $q = 2$ 또는 $q = -2$ 중 가능한 것). 조건 분석으로 $\alpha = -\beta$, 즉 $q(x) = c (x^4/4 - \beta^2 x^2/2) + 2$.

    $q(\beta) = -\beta^4 c/4 + 2 = 4 \Rightarrow c = -8/\beta^4$. $q(1) = -\dfrac{8}{\beta^4}\cdot\dfrac{1 - 2\beta^2}{4} + 2 = \dfrac{2(2\beta^2 - 1)}{\beta^4} + 2 = \dfrac{23}{8}$ 정리하면

    $$
    7 \beta^4 - 32 \beta^2 + 16 = 0\quad\Longleftrightarrow\quad (\beta^2 - 4)(7\beta^2 - 4) = 0
    $$

    $\beta^2 = 4$ 또는 $\beta^2 = 4/7$. 각각 대입:

    $$
    q(x) = -\frac{x^4}{8} + x^2 + 2 \quad\text{또는}\quad q(x) = -\frac{49}{8} x^4 + 7 x^2 + 2\quad\square
    $$

    !!! tip "큰 그림"
        - **(1)** $g(t)$ 의 점프 위치 $t = 0, 2, 3$ 은 $p$ 의 임계점 (극소 $0, 3$) 과 "최솟값 추월 위치" $2$ ($p(2) = p(0)$). $g$ 의 구간별 식이 $p'$ 의 인수 구조와 $p(2) = p(0)$ 조건을 직접 명시한다.
        - **(2)** 미분가능 조건이 합성함수의 좌·우 도함수 비교로 환원되고, 그 결과 $q'(0) = 0$ 와 $q$ 의 대칭성 $\alpha = -\beta$ 가 강제된다. 두 풀이가 공존하는 이유: $\beta^2$ 의 4차 방정식이 두 개의 양수 근 ($4$ 와 $4/7$) 을 가짐.

**연습문제 (보충 10).** [piecewise 함수의 한쪽 극한 곱 + 연속 + 치환적분]

다항함수 $f(x)$ 에 대하여 함수 $g(x)$ 는 다음과 같다.

$$
g(x) = \begin{cases} 3 x & (x < 0 \text{ 또는 } x > 3) \\ f(x) & (0 \le x \le 3) \end{cases}
$$

또 $h(x) = \displaystyle\lim_{t \to 0^+} g(x + t) \cdot \lim_{t \to 3^+} g(x + t)$ 라 하자. $h(x)$ 가 모든 실수에서 연속이고 $\displaystyle\int_{-5}^{5} h(x)\,dx = 600$ 일 때 (1) $f(0) + f(3)$, (2) $\displaystyle\int_0^3 x\,f(x)\,dx$ 를 구하시오.

??? success "연습문제 (보충 10) 풀이"

    **(1).** $X = x + t$ 치환으로 $\lim_{t \to 0^+} g(x + t) = \lim_{X \to x^+} g(X)$. $\lim_{t \to 3^+} g(x + t) = \lim_{X \to (x + 3)^+} g(X)$. 구간별 정리:

    $$
    h(x) = \begin{cases} 3 x \cdot 3(x + 3) & (x \ge 3) \\ f(x) \cdot 3(x + 3) & (0 \le x < 3) \\ 3 x \cdot f(x + 3) & (-3 \le x < 0) \\ 3 x \cdot 3(x + 3) & (x < -3) \end{cases}
    $$

    연속성: $x = 3$ 에서 $9 \cdot 18 = f(3) \cdot 18 \Rightarrow f(3) = 9$. $x = 0$ 에서 $f(0) \cdot 9 = 0 \Rightarrow f(0) = 0$. $x = -3$ 에서 $-9 f(0) = -9 \cdot 18 \cdot 0$ — 이미 $f(0) = 0$ 으로 만족.

    $\boxed{f(0) + f(3) = 9}\quad\square$

    **(2).** $\displaystyle\int_{-5}^5 h(x) dx$ 를 4 구간으로:

    $$
    \int_{-5}^{-3} 9 x(x + 3) dx + \int_{-3}^0 3 x f(x + 3) dx + \int_0^3 3 f(x)(x + 3) dx + \int_3^5 9 x(x + 3) dx = 600
    $$

    1번째 적분: $\int_{-5}^{-3} (9 x^2 + 27 x) dx = [3 x^3 + \tfrac{27}{2}x^2]_{-5}^{-3} = (-81 + \tfrac{243}{2}) - (-375 + \tfrac{675}{2}) = 78$.

    4번째 적분: $\int_3^5 (9 x^2 + 27 x) dx = [3x^3 + \tfrac{27}{2}x^2]_3^5 = (375 + \tfrac{675}{2}) - (81 + \tfrac{243}{2}) = 510$.

    합: $78 + 510 = 588$, 따라서 가운데 두 적분의 합 $= 12$.

    치환적분: 2번째 적분에 $u = x + 3$ ($du = dx$, $x = u - 3$, $x: -3 \to 0 \Leftrightarrow u: 0 \to 3$):

    $$
    \int_{-3}^0 3 x f(x+3) dx = \int_0^3 3(u - 3) f(u) du
    $$

    더하면

    $$
    \int_0^3 3(u - 3) f(u) du + \int_0^3 3 f(u)(u + 3) du = \int_0^3 6 u f(u) du = 12
    $$

    $\boxed{\displaystyle\int_0^3 x\,f(x)\,dx = 2}\quad\square$

    !!! tip "핵심"
        - **편향 극한 (한쪽 극한)** $\lim_{t \to 0^+} g(x + t)$ 는 $g$ 의 $x$ 에서의 **우극한**. piecewise $g$ 가 $x = 0$ 에서 $3 \cdot 0 \ne f(0)$ 의 점프를 가지므로 우극한은 $f(x)$ 분기 또는 $3 x$ 분기를 선택.
        - **치환적분으로 $f(x + 3)$ 의 적분을 $f(u)$ 적분으로 통일**: 두 부분 적분이 합쳐져 $\int 6 u f(u) du$ 단일 형태.

**연습문제 (보충 11).** [piecewise 유리함수의 최댓값 + 미분불가능점 + 교점 개수]

양수 $a$ 와 상수 $b$ 에 대하여

$$
f(x) = \begin{cases} \dfrac{2x}{x^2 + a} & (x \ge 0) \\ b x & (x < 0) \end{cases}
$$

실수 $t$ 와 양수 $c$ 에 대하여 $[t, t + c]$ 에서 $f(x)$ 의 최댓값을 $g(t)$ 라 할 때, 다음을 만족한다.

> (ㄴ-가) $x \ge 0$ 모든 실수 $x$ 에서 $f(x) \le f(c)$.
> (ㄴ-나) $g(t)$ 는 $t = -1/2$ 에서 미분불가능.

기울기 $m$ 인 직선 $\ell: y = m t + \dfrac{1}{c}$ 에 대하여

> (ㄷ-가) $m = 1/25$ 일 때 $\ell$ 과 $y = g(t)$ 가 서로 다른 두 점에서 만남.
> (ㄷ-나) $0 < m < 1/25$ 일 때 $\ell$ 과 $y = g(t)$ 가 서로 다른 세 점에서 만남.

$a, b, c$ 의 값을 구하시오.

??? success "연습문제 (보충 11) 풀이 (요약)"

    **(가) 조건에서 $a = c^2$.** $f'(x) = \dfrac{2a - 2 x^2}{(x^2 + a)^2}$ 는 $x = \sqrt a$ 에서 $0$. $f(c) = $ 최댓값 ⇒ $c = \sqrt a$, 즉 $a = c^2$. 이때 $f(c) = 1/c$.

    **(나) 미분불가능점 → $c = 1/2$ ($b \ge 0$ 경우) 또는 $\alpha = 1/2 < c$ ($b < 0$ 경우).** $g(t)$ 는 $f$ 의 모양에 따라 piecewise. $b \ge 0$ 라면 $f$ 가 $x \ge 0$ 전구간에서 양수이고 $x = c$ 에서 최대 $1/c$. $g(t)$ 의 piecewise 분기는 $t = -c$ 와 $t = 0$ 에서. $t = -1/2$ 가 미분불가능 ⇒ $c = 1/2$.

    이때 $f(0) = 0$, $g(0) = 2$ (== 직선 $\ell$ 의 $y$ 절편 $1/c = 2$). 직선이 $g$ 와 교점 개수:
    
    - $b \ge 1/25$: $0 < m \le 1/25$ 일 때 2개 (조건 만족).
    - $b < 1/25$: $m = 1/25$ 일 때 3개 (조건 위반).

    제시문 (ㄷ-나) 의 "세 점" 조건이 별도로 필요 ⇒ $b \ge 0$ 만으로는 (다) 만족 불가. 따라서 $b < 0$.

    **$b < 0$ 분석.** $f$ 가 $x < 0$ 에서 감소, $x = 0$ 에서 $0$, $x \ge 0$ 에서 $x = c$ 에서 최대 $1/c$. $f(-\alpha) = f(c - \alpha)$ 인 $\alpha \in (0, c)$ 가 존재. $g(t)$ 의 piecewise:

    $$
    g(t) = \begin{cases} b t & (t \le -\alpha) \\ \dfrac{2(t + c)}{(t + c)^2 + a} & (-\alpha < t \le 0) \\ 1/c & (0 < t \le c) \\ \dfrac{2 t}{t^2 + a} & (c \le t) \end{cases}
    $$

    미분불가능 $t = -1/2$ ⇒ $\alpha = 1/2 < c$. $g(0) = 1/c$. 그래프상 $\ell: y = mt + 1/c$ 가 $(0, 1/c)$ 와 $(-1/2, -b/2)$ 를 잇는 기울기 $1/25$:

    $$
    \frac{1/c - (-b/2)}{0 - (-1/2)} = \frac{1}{25}\quad\Longrightarrow\quad b = \frac{1}{25} - \frac{2}{c}
    $$

    또 $g$ 가 $t = -\alpha = -1/2$ 에서 위 분기와 아래 분기가 연결: $-b/2 = 2(c - 1/2)/((c - 1/2)^2 + a)$, 즉 $b = -\dfrac{4(c - 1/2)}{(c - 1/2)^2 + c^2}$. 두 식 일치:

    $$
    \frac{-4(c - 1/2)}{(c - 1/2)^2 + c^2} = \frac{1}{25} - \frac{2}{c}\quad\Longleftrightarrow\quad 8c^3 - 4 c^2 + c - 50 = 0
    $$

    $(c - 2)(8 c^2 + 12 c + 25) = 0$ ⇒ $c = 2$. 따라서 $a = 4$, $b = 1/25 - 1 = -24/25$.

    $\boxed{a = 4,\ b = -\dfrac{24}{25},\ c = 2}\quad\square$
